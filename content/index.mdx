Tether is a reactive backend framework for Go. You write queries and mutations as Go functions. Tether tracks the data each query reads and pushes fresh results to connected clients over WebSockets whenever that data changes.

The examples use a Go server with a React client. Client examples also have a **TypeScript** tab for apps that use `@tetherdb/client` directly.

## What these docs cover

These docs describe Tether Go engine 1.3.1, `@tetherdb/react` 1.2.0, and `@tetherdb/client` 1.0.0. Go examples use GORM with SQLite or PostgreSQL. TypeScript types in the examples describe your app's JSON responses; Tether doesn't generate them from your Go models.
